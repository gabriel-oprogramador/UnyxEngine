# Unyx Engine
Minimal C++ game engine built with a true ECS and Data-Oriented Design (DoD) principles.  

Unyx is a lightweight engine focused on simplicity, learning, experimentation, and building games from the ground up.  

This project is developed independently as a way to explore game engine architecture, low-level programming, ECS design, rendering, and other core systems.  

Throughout its development, Unyx will be used to create games and experiments, allowing the engine to evolve naturally through real-world usage.  

The name **Unyx** comes from **Onyx**, a gemstone associated with strength and durability.
