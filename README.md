# Unyx Engine

Minimal C++ game engine built around a true ECS architecture and Data-Oriented Design (DoD) principles.

Unyx is a lightweight engine focused on simplicity, learning, experimentation, and building games from the ground up.

This project is developed independently as an opportunity to explore game engine architecture, low-level programming, ECS design, rendering, and other core systems.

Throughout its development, Unyx will serve as a foundation for games and experiments, allowing the engine to evolve naturally through practical use.

The name **Unyx** is inspired by **Onyx**, a gemstone traditionally associated with strength and durability.
